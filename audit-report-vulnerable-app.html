The application constructs SQL queries using direct string concatenation of user-supplied input, allowing attackers to manipulate the query structure.

MEDIUM CWE-664 PERFORMANCE

N+1 Database Query Pattern

#PERF-001
📁 src/services/report.service.ts : L6 - L11
const reports = await Promise.all( users.map(async (u: any) => { const orders = await db.query(`SELECT * FROM orders WHERE user_id = ${u.id}`); return { ...u, orders }; }) );

The code executes one database query for the initial list of users, followed by one additional query per user to fetch orders, causing significant latency as the user base grows.

Impact: Degraded application performance and excessive database load.
Proposed Remediation: Use a single JOIN query or a single query with an 'IN' clause to fetch all required data in one round-trip.
