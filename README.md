# 🛡️ AI Code Auditor

> Autonomous Repository Security, Performance & Architecture Auditor powered by Gemini 1M Context Window. **100% Free-Tier Architecture.**

---

## ⚡ Quick Start

### 1. Prerequisites
- Node.js >= 18.x
- A free Gemini API key from [Google AI Studio](https://aistudio.google.com/) (no credit card required)

### 2. Setup
```bash
# Clone or enter directory
cd d:\projects\code-auditor

# Copy environment template
copy .env.example .env

# Add your free Gemini API key to .env
# GEMINI_API_KEY=your_free_key_here
```
